# Oaths & Omens — Action Cards

The action card pool is not yet designed (see rulebook.md's Open Items). This
file is a placeholder for that list.

Cards are face-up and visible to all players at all times. Playing a card
costs its listed resources, requires meeting its stated conditions, and is
then discarded. The deck reshuffles from the discard pile once empty.

## Schema

Each card needs:

| Field | Description |
|---|---|
| Name | |
| Cost | Resources spent to play (Wood / Iron / Clay / Fish) |
| Condition | Requirement that must be met to play the card, if any |
| Effect | What happens when played |
